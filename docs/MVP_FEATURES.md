# MVP Features

Do not build everything. Build this first:

## Owner side

- Login
- Dashboard
- Machines
- Locations
- Products
- Machine slots
- Inventory
- VMS import
- Refill recommendations
- Routes
- Cash variance
- Issues

## Operator side

- Today’s route
- Pick list
- Machine refill screen
- Cash collection screen
- Cleaning checklist
- Issue report
- Return leftovers

## Not in MVP

- Customer loyalty app
- AI route optimization
- Full accounting system
- Native mobile app
- Complex ad platform
- GPS tracking
- Predictive purchasing beyond simple low-stock alerts
