# Snacky OS Build Order

## Phase 1: Company memory

Build and clean:

- Locations
- Machines
- Products
- Suppliers
- Team members
- Storage locations
- Machine slots/planogram

Goal: every machine and product has one clean identity.

## Phase 2: VMS data

Build:

- VMS machine mapping
- VMS product mapping
- VMS stock import batch
- VMS stock snapshots
- VMS sales snapshots

Goal: VMS data enters Snacky OS and updates machine stock.

## Phase 3: Inventory ledger

Build:

- Purchase received
- Storage to operator bag
- Operator bag to machine
- Operator bag to storage
- Damaged/expired/missing adjustments

Goal: know where every product went.

## Phase 4: Refill engine

Build:

- Refill recommendation view
- Refill order generation
- Route assignment
- Pick list generation

Goal: system tells the operator what to take.

## Phase 5: Operator workflow

Build mobile screens:

- Today’s route
- Pick stock
- Machine stop
- Fill quantities
- Collect cash
- Cleaning checklist
- Upload photo
- Report issue
- Return leftovers

Goal: operator follows the system, not memory.

## Phase 6: Owner dashboard

Build:

- Sales
- NSM by machine
- Gross margin
- Rent %
- Cash variance
- Open issues
- Stockouts
- Products to buy
- Machines to move

Goal: owner makes decisions from data.
