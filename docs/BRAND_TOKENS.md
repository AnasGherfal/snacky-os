# Snacky Brand Tokens

The exact production brand palette was not available in code, so these tokens were sampled from the supplied Snacky logo artwork and kept intentionally restrained for the internal OS.

| Token | Value | Use |
| --- | --- | --- |
| `--snacky-primary` | `#f5820b` | Primary actions, focus accents |
| `--snacky-primary-hover` | `#d96f05` | Primary action hover |
| `--snacky-accent` | `#3f6f3f` | Active navigation and selected states |
| `--snacky-neutral-background` | `#f8fafc` | Main application background |
| `--snacky-border` | `#e2e8f0` | Card and table borders |

Main surfaces should remain white or neutral. Use the orange and green tokens as accents only, especially on finance and admin pages.
